🛰️ AURA - Astronaut Health Monitor

**NASA Space Apps Challenge 2026 | Human Research Program**

A visual, interactive tool that helps astronauts assess their own health during space missions and provides guidance on treatments and health improvements.

![HTML](https://img.shields.io/badge/HTML-5-orange)
![CSS](https://img.shields.io/badge/CSS-3-blue)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)
![NASA](https://img.shields.io/badge/NASA-Space%20Apps-red)

🚀 Live Demo
Just open `index.html` in any browser. No install needed.

✨ Features
- **👨‍🚀 Clickable Human Body Map:** Click Brain, Heart, Lungs, Muscle, Bone, Skin to see function, spaceflight risk & treatment
- **📊 Live Vitals Dashboard:** Heart Rate, SpO2, Temperature, Blood Sugar, BP, Sleep - with Green / Yellow / Red color coding
- **📈 Dynamic Charts:** 7-day trend of HR, Blood Sugar, Sleep using Chart.js
- **🎮 Gamification:** XP, Streak, Progress Bar, Badges to keep astronauts engaged
- **🌍 5 Environments:** ISS, Orion Spacecraft, Lunar Base, Mars Base, Rover EVA
- **🩺 AI Health Guidance:** Instant assessment - GO / CAUTION / NO-GO for EVA + action plan
- **📸 Image Upload:** Upload ultrasound / skin image for quick check
- **🚨 Emergency Button:** One-click alert to Flight Surgeon
- **❓ Simple Instructions:** How to measure each vital in space

🧬 Science - NASA Human Research Program
| Hazard | Effect | Our Solution |
| :--- | :--- | :--- |
| Microgravity | Bone loss 1%/month, Muscle loss | ARED Exercise + Calcium tracking |
| Radiation | SANS, vision changes, cancer risk | Vision test, Dosimeter guidance |
| Isolation | Stress, Sleep loss | Meditation, Sleep tracking |
| Altered Gravity | Heart weakening | HR + BP monitoring |
| Dust / CO2 | Lung irritation | SpO2 monitoring |

⚠️ When to Alert Flight Surgeon?
- SpO2 < 95% - Low Oxygen
- Temp > 38.5°C - High Fever
- Blood Sugar < 70 or > 180 mg/dL
- Heart Rate < 60 or > 100 bpm
- Bone loss > 1.5%

🛠️ Tech Stack
- HTML5, CSS3, JavaScript (Vanilla)
- Chart.js for dynamic charts
- Single file - Works offline in space!
